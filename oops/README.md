Q3. Interview question: Explain the difference between a class and an object using a real-life example.

Ans : 1. Class: It is template used to create a object 
    e.g: suppose we make a building before making build we have plan on paper that is 
            blueprint of building know as Class.
    Note: It is reusable structure code called Class.

      2. Object: It is real-world, run time entity that represent an instance of the class
                 It is fundamental building block that consist of two things : 
                    State : (attributes/properties)
                        what object knows or hold ( such a variable)
                    Behaviour: (methods/functions)
                        what object can do ( its functions)
